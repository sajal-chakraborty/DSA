## 📝 Program to Find the Longest Sub Array Where the Sum of Elements is ZERO

### 📄 File Name: `LongestZeroSumSubArray.py`

This program finds the longest subarray with a sum of zero. It uses a hash map to store the cumulative sum and its indices, allowing for efficient lookups. The algorithm runs in **O(n)** time complexity.

### 🚀 Usage

To use this program, simply call the function `find_longest_zero_sum_subarray(arr)` with an array of integers as the argument.

### 🔧 Implementation

Here are the steps to implement the logic for `LongestZeroSumSubArray.py`:

1. **Initialize Variables**:
    - Create a hash map (dictionary) to store the cumulative sum and its corresponding index.
    - Initialize variables to keep track of the maximum length of the subarray and the starting index.

2. **Iterate Through the Array**:
    - Loop through each element in the input array while maintaining a cumulative sum.

3. **Check for Zero Sum**:
    - If the cumulative sum is zero, update the maximum length and starting index.

4. **Store Cumulative Sum in Hash Map**:
    - If the cumulative sum has been seen before, calculate the length of the subarray from the previous index to the current index.
    - If this length is greater than the maximum length found so far, update the maximum length and starting index.

5. **Return the Result**:
    - After iterating through the array, return the longest subarray found using the starting index and maximum length.

### 📦 Usage

To use this program, simply call the function `find_longest_zero_sum_subarray(arr)` with an array of integers as the argument.
